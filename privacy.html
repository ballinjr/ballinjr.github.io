Privacy Policy

Last updated: October 24, 2026

Ballin Jr Uploader is a private tool used only by the owner of the YouTube channel Ballin Jr to upload and schedule his own videos. It has no other users.

What the app accesses

With the owner's permission, the app uses the YouTube Data API to upload videos, set thumbnails, set publish times and manage playlists on the owner's own channel, and the YouTube Analytics API to read that channel's own statistics.

What is stored

The sign-in token is stored only on the owner's own computer. The app does not collect, sell or share any personal data, and does not access any other person's account or data.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
